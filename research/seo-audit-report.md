## Priority SEO fixes

1. Add or improve semantic H2/H3 headings on older standalone pages, especially About and Privacy.
2. Replace stale or placeholder Open Graph and Twitter image metadata with a deployable site asset.
3. Add Twitter card metadata to pages that have Open Graph metadata but no Twitter fields.
4. Add sitemap.xml and robots.txt with the canonical domain and public page list.
5. Keep one search-intent-focused H1 per page, then use H2 sections and H3 subsections in a logical order.
6. Add page-specific JSON-LD where the content type supports it: WebApplication for tools, FAQPage for question sections, and Article or BlogPosting for editorial pages.
