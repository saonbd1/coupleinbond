# Contact Form Preview Verification

## Visual check

The Contact page now shows a pink-to-lilac form card inside the existing editorial article shell. It includes name, email, topic, and message fields, a clear delivery note, and a theme-matched submit button.

The redesigned three-section footer remains visible below the page content. The header keeps the brand and wallet control.

## Interaction check

An empty submission marks all four required fields as invalid and shows: “Please fix the highlighted fields before you continue.”

A valid local submission shows: “Your message is ready. This static page does not send or store messages until a delivery service is connected.” The form resets after this local confirmation.
