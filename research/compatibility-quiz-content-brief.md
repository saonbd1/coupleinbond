# Compatibility Quiz and Relationship Tips: Page Brief

## Recommended page

**URL:** `/compatibility-quiz.html`  
**Working title:** Relationship Compatibility Quiz: Explore Your Connection  
**Primary keyword:** `relationship compatibility quiz`  
**Search intent:** Interactive informational. The visitor wants a quick way to explore compatibility and receive a useful next conversation.

## Editorial angle

CoupleIn Bond already offers a playful name-based love calculator. This page must do a different job. It asks about values, communication, conflict repair, shared time, and future direction. It gives a reflection result, not a prediction.

> A quiz can start a conversation. It cannot decide whether a relationship will last.

This framing follows the public relationship-education pattern found in Relate, HelpGuide, the Gottman Institute, and One Love Foundation.[1] [2] [3] [4]

## Page structure

The page opens with the interactive quiz above the fold. Each question uses a four-point answer scale so the tool stays fast on mobile. The result shows a broad connection profile and one suggested action. The result does not label a couple as good, bad, healthy, unhealthy, compatible, or incompatible.

The five reflection areas are values and goals, communication, conflict repair, time and affection, and shared direction. These themes create a clear distinction from name-based scoring while still linking naturally to the existing calculator.

Below the quiz, the page explains how to read the result and gives five practical relationship tips. The tips use short actions: ask an open question, reflect back what you heard, name the support you need, set a weekly check-in, and choose one shared ritual.

The page ends with five direct FAQ questions. The FAQ answers explain what the quiz measures, whether it is accurate, whether it stores answers, and how it differs from the name calculator.

## Responsible-use language

The page must state that the quiz is for entertainment and reflection. It does not diagnose, predict, or replace professional support. The browser stores only the current result for the current session. No relationship answers are sent to a server.
