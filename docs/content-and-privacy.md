# Content and privacy

The project combines editorial content with browser-based tools. Public pages should explain what an interaction does before asking someone to enter information or connect a wallet.

## Local data

Some features store data in the browser, including poll choices and Community Book notes. This data can be lost when browser storage is cleared or when a visitor changes browsers or devices.

## Wallet interactions

Wallet connection and blockchain minting are separate from the core site. A wallet address and transaction details may be visible on the relevant blockchain when a user chooses to mint.

For the site's current legal and privacy language, use the public [Privacy page](https://couplein.bond/privacy.html). Keep this documentation descriptive and update it when the product's storage, wallet, or sharing behavior changes.
