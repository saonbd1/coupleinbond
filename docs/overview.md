# What the project is

Couple in Bond is a browser-first collection of relationship tools and ideas. It is designed for couples, friends, and anyone looking for a gentle prompt to start a meaningful conversation.

## Main experiences

- **Love Calculator:** creates a playful connection score from two names.
- **Community Polls:** asks relationship questions and keeps a visitor's vote in the browser.
- **Love Quotes:** presents short, shareable words and optional quote image minting.
- **Relationship Blog:** publishes practical ideas, activities, and communication exercises.
- **Community Book:** lets visitors write a short local note that remains on their device.
- **Keep the Moment:** explains the optional blockchain flow for preserving a generated result or quote image.

The site is intentionally lightweight: the public experience is made from HTML, CSS, JavaScript, and static assets.
