# Project structure

| Location | Purpose |
| --- | --- |
| Root HTML files | Homepage, tools, contact, privacy, and other public pages |
| Root CSS and JavaScript | Shared layout, navigation, interactions, and page-specific behavior |
| `blog-posts/` | Long-form relationship articles |
| `polls/` | Individual poll experiences |
| `assets/` | Images and other static media |
| `contracts/` | Solidity contracts used by optional NFT flows |
| `docs/` | Curated GitBook documentation |
| `research/` | Internal content briefs, audits, and verification records |

The deployed website and the GitBook are separate publishing surfaces. The website serves the interactive experience; GitBook explains the project and its implementation.
