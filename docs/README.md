# Couple in Bond documentation

Welcome to the project guide for Couple in Bond.

Couple in Bond is a static relationship website built around small, approachable ways to connect: playful tools, thoughtful prompts, community questions, and optional digital keepsakes.

Use the navigation to learn how the site works, run it locally, understand the repository, and review the optional Ink Chain NFT features.

For the public website, visit [couplein.bond](https://couplein.bond/).

## GitBook setup

This folder is designed to be connected to GitBook through the GitHub integration:

1. Connect the `saonbd1/coupleinbond` repository.
2. Select the branch containing this documentation.
3. Select `docs/` as the documentation location.
4. Use `docs/SUMMARY.md` as the navigation source when GitBook asks for a summary file.
5. Publish the space after reviewing the imported pages.
